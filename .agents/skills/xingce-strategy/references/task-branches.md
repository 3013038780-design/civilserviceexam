# 从真题补出的执行分支

适用于题干给了规则、公式、流程或图表的题。先辨真正要求的操作，再选方法；十一类是学习导航，不能代替操作分流。本页来自2024、2025副省级题面阅读及所列样例核验，仍是候选规则，不等于全部语料已读或整类有效。

## 定义中的自定规则：先按题目设定执行

**信号：** 题干给符号、数位、比较顺序、公式或命名后的推理形式，问大小、顺序、升降或是否属于该形式。

**首选动作与理由：**

1. 把题内规则改成操作指令，明确输入与输出。例如“从右侧高位开始比较”，而非默认从左向右。
2. 分开写不同位置或对象的规则。一个符号在高位与低位的排序可能不同，不能合并成一张全局大小表。
3. 先执行最有区分力的一步；高位已分出大小，就不再计算低位；高位相同才看下一位。
4. 公式题先核变量的对象与意义，再判断分子、分母的变化。不在定义范围内的行为，算术形式像也不能选。
5. 若题目要求识别一种推理形式，保持变量位置和量词不变；“符合题中定义”和“在一般逻辑中有效”是不同任务。

**停止：** 唯一候选满足题内规则；形式识别还须满足题干其余条件。

**题内依据：** 2024副省级第91题（公式与包含关系）、第94题（左右位使用不同排序）；2025第93题（比值及传播对象范围）、第100题（形式识别）。第91、94、100题已与配套机构参考比较，不能把机构参考称为官方答案。

**自拟反例：** 数位从右向左变为从左向右，原先由右位排除的候选可能改变；同一比值的分母变大也可能被分子更大的增幅抵消。只有“分母变大”而没有其余条件，不能断言整体下降。

**边界：** 不把题内命名升级成现实中的正确理论；题干要求判断论证是否有效时，要用有效性规则，不能只匹配形状。

## 定义中的流程与算法：检查每一步是否合法

**信号：** 题干给测量、提取、建模、验证等阶段，或给树图、搜索与回退规则。目标是排序或路径，而非生活案例贴标签。

**流程排序：**

1. 先写“这一步要用到什么”，建立前置依赖。例如模型验证需要已有模型。
2. 用一组确定先后排选项，避免先把全部步骤重排；随后核其他依赖，防止局部正确而全局错误。
3. 不认识技术名称时，可以利用输入输出依赖，但题内明确次序优先。

**树图执行：**

1. 明确当前位置、尚未处理的子分支、允许的回退和目标节点。
2. 沿候选路径走，只检查相邻两步是否合法；发现首个违规就排除。
3. 按题干规则，尚有未处理子节点时不能提前回退；无可扩展分支时回到父节点。不能从一个叶节点直接跳到同级叶节点。
4. 已到目标就按终止规则停止。题干未规定“从左到右”时，不额外增加这个限制。

**停止：** 流程的唯一候选满足全部依赖；路径的唯一候选每步合法并按要求到达目标。

**题内依据：** 2025副省级第94题（流程依赖）和第96题（树图搜索）。已读完整题面与第18页树图，并与机构解析逐项比较；这是同卷题内核验，跨年算法变体尚待继续找题。

**自拟反例：** 在有效路径中删掉“叶节点→父节点”这一步，会出现图上不存在的跨叶连线；若题目改成广度优先搜索，深度优先的整套顺序不能直接复用。

**来源：** 本项目根据给定定义与图推导；没有借用未读取的算法题库，也不需要先掌握整门计算机课程。

## 资料趋势图：先辨纵轴，再找最省的一处差异

**信号：** 选折线、柱形或时间段，图上画的量可能是总量、同比增量、增长率、比重或平均数。

**首选动作与理由：**

1. 用一句话写纵轴：“每年的增加数量”或“每台价格”等。输入图里的线形不能直接当目标线形。
2. 建所需关系：增量用相邻年份量相减；增速再除以上年量；比重与平均数用对应分子除分母。
3. 看选项差别：有的只差一个上升/下降方向，有的只差最高点位置，有的还差相近点的高度。先选能排除候选的最少比较。
4. 增量图先查正负、峰谷与顺序；没有标零轴的示意图不能凭点画在纸面上方就认定增量为正。
5. 比值趋势可交叉相乘判升降，但两分母必须为正；近似结果仍可能跨越分界时再精算。
6. 剩一项后，用另一个决定性位置核对；若候选共享同样峰谷，就继续比较相对高度，不能把“只看峰谷”当万能法。

**停止：** 已核关系把其余候选全部排除，唯一候选的必要形状无冲突。无需算完所有年份所有小数。

**题内依据：** 2024副省级第125题（增量图，不给零轴）；2025第120题（增量图，明确给零轴）、第125题（平均数图）、第130题（比重图）。四题题面图与机构参考已读取。本项目另做了数值复算，核验记录在本地研究目录，不伪装成独立盲测。

**自拟反例：** 总量从100、120、130上升，增加量却从20降到10；不能将总量上升判成增量上升。相同“先降后升”的两条图线也可能有不同最高点，趋势同向并不足以选答案。

**来源与状态：** 本轮题面推导，不声称来自名师未读章节。上述图匹配规则目前是小样本核验；负数、近界值与相同比例等边界继续补题检查。

## 共享条件题组：复用底表，不继承临时条件

**信号：** 数道题共享人员、项目、配额和条件，每小题再给一个“若”。先保存共享约束与双向关系，再为每题单独加入附加条件。每题结束撤销附加条件及由它推出的结论。

**首选：** 配额满员先排人；“每人至少一次”用于检查剩余席位；问可能时用一个完整合法安排支持，问一定时尝试构造反例。只找到支持例不能证明必然。题面给具体候选时优先用最硬条件排除，再核剩余候选的全部约束，不必穷举。

**停止与边界：** 问可能已有完整合法安排，问一定有有效推导且竞争项已排定。人数、席位、每人次数必须按题面，不默认每人最多一个项目；不能把上题的临时条件当下一题前提。

**依据：** 2026地市106—110题已在对应解析读取前保存首答DBABD；随后枚举24个合法总安排并与机构五题解析核对一致。行政执法卷为同一题组，不能再计一组独立样本。给用户的是配额和条件推导，工具枚举只作核验。2025地市106—110题随后在参考前保存DBDAB，42个合法季度分配复核且与机构参考一致；2025执法为同题组换序，不另计独立样本。现有两个年份、两个不同题组的助手样例，仍非整类验证。

**新增边界：** 会议先后是季度内时间的先后，不等于季度编号严格小于。先写乙→丁→丙→甲、己→丙；同季度有空位可按依赖排序。只有题干明确不同季度，才能把季度关系改为严格不等式。2025第107题第二季度已被丁、辛占满，乙在丁之前且不能再入第二季度，才被迫到第一季度。

## 平均数换分母：先还原统计对象

**信号：** 材料给“每件已产业化”收益，问题问“每件有效”专利收益。写出两个分母，利用“产业化率=已产业化件数÷全部有效件数”，得到每件有效收益=每件已产业化收益×产业化率，然后再比较或求比。

**停止与边界：** 对象、时期和单位已经对齐，结果可区分选项。若两个平均本来同口径，不额外乘率；若转化率缺失，不能猜一个数字继续算。其他领域的“每人”也可能是全部人员或已参加人员，须逐题检查。

**依据：** 2026执法118题原图、扫描参考PDF65页OCR已读，复算约0.775对应0.8。保留图未齐时暂定C、读图后A的修订，不将暂定候选算完整首答或新盲测。不能把模型补齐未知数字的倾向当解题能力。

## 信息可求性：用两个合法模型证明不唯一

先列目标最少需要什么：上一年值需要变化关系；总体平均需要对应件数权重；行业×规模交叉率不能仅由两边总体率拼出。缺项时尝试构造两种都满足已知、目标却不同的情况。能构造就证明不唯一；其他条件可能补足缺项，不能把“没直接给”当不可求的充分条件。

2026执法120题题图与扫描参考PDF66页OCR已读，三项分别缺年份变化、数量权重、交叉类别率，与机构参考0项一致。2025地市130题另存首答B并核对解析：基期一般贸易额可由基期整体乘基期比重求得；季度量和某月同比率却不能确定该月额度。由此增加跨年任务样例；2024副省135仍为后续入口。

## 论证范围：选项是否攻击了结论实际说过的话

先圈结论对象、范围与时间，再写选项质疑的范围。“只研究数学”不是对“数学学习能力受影响”的反驳；只有当结论确实推广到其他学科时，跨学科证据不足才击中外推。范围之外的质疑并非在所有论证里都无效，须按本题结论检查。

依据为2026执法105题及扫描机构参考PDF58—59页OCR；本题选不能削弱，工作答案C与参考一致。该题研究叙述只作为给定论证材料，没有被本项目独立核实为AI教学效果证据。


## 言语问题解释：提到一个现象，不等于解释了它

**信号：** 设问是“能够解释哪一问题”“没有解释哪一问题”“无法解释”，选项往往写“为什么”“如何”。这不是主旨题，不先找一条概括全段的话。

**动作与理由：**
1. 先圈正反方向，再把每个选项改成一个问句，并圈具体询问对象。例如问“为什么适合干旱区”，不是问“什么是熔盐堆”。
2. 找文中能直接回答问句的一句或一条机制链。若问原因，应有导致该结果的依据；若问怎么做，应有对应过程或方式。
3. 区分结果、过程、原因、比较关系。给出数量、毒性倍数或“发生了某变化”，不能自动回答它怎样计算、为何更强或怎样发生。
4. 科技术语陌生时先保留原词，核对关系；不从常识补文段没有解释的内容。若材料自身以概括机制回答问题，不额外要求它达到专业论文的微观精度。

**停止与边界：** 选正时有可定位回答且其余候选缺所问信息；选非时逐项确认三项已被回答、一项缺失。不能只因为某个主题词出现过就说已解释，也不能把所有“如何”题都排除。

**已读样例：** 2025地市56、64及执法58、65题正文与机构解析已读；本组在答案表已接触后做教学核对，非盲测。64题“用氟化盐冷却→依赖水较少”足以解释为何可在干旱区建造；56题给储量结果并未给储量换算过程。执法58问的是信息载体差异，材料给物理机制差异不能自动替换；65给毒性比较值未解释该比较的原因。四题同年，不称跨年检验。

## 论证比较：不能把主体匹配变成词面过滤器

2025执法102首答C、机构参考D，当前保留最强项分歧，不作为方法成功样例。参考以“其他国家企业与H国主体不同”排C的理由不充分：国际竞争本来就是比较关系。应检查对手成本变化怎样影响相对优势，及本国是否可能同样降本。D提示原有技术质量优势减弱，但没有直接隔离原料成本的因果作用，不能只因它重述了结论中的竞争力便判定最强。未判清前不把C/D选择教成定论。

2025执法105首答C、参考D，复核暂采D：C说留下的“不一定”是大果，D明确描述缺肥与营养不足，后者为结果提供了更具体的竞争解释。不过其他原因可以共存，D不证明早套袋毫无影响。“有他因=原因完全无效”“肯定词=永远更强”均不可入库。
