# 对照与方法卡

## 独立对照

1. 登记卷名、年份、类别、来源、日期、文件摘要与完整度，分离参考答案。图形和图表以原图核验。
2. 用户只记题号、选项、用时（单题或题组）、把握程度（确定／犹豫／猜）及跳题，不强制逐题口述中断考试。题组计时不能假装为单题用时。
3. AI在查看答案表前保存首答与依据。事实核查与查看现成解析区分，提前接触写入记录。模型训练期间是否见过题不可确定，不称严格科研盲测。
4. 核验另存结论，不覆盖首答。参考冲突、缺题或无法确定进入待核验。
5. 双方提交后分类：双方对、用户错AI对、用户对AI错、双方错、待核验；另看猜对、慢题和高把握错题。
6. 先处理主攻模块，每次形成少量方法卡；数量图推保留记录，不自动扩成专项。

## 方法卡

记录方法名、题型、识别信号、需要读的部分、知识前提、最简步骤、允许近似、停止与检查、反例及换方法条件、例题题号、来源。

状态分候选、例题已核验、用户新题已独立应用；一次对题不代表长期掌握。

## 计分

未确认的权重只用于情景估算。报总题数、正确数、模块正确率和计时，注明估分模型；无真实成绩报告不称达到官方65分。跳题、猜对和确定答对分别记录。目标模块完成率与时间成本优先于解析篇幅。
