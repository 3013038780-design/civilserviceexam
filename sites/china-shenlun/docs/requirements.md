# 学习资料与网站需求

本需求落实用户关于系统了解中国、官方原文可追溯、每日学习、最小必要表达及申论实际应用的约定。总任务为Issue #6，完整课程在Issue #8，本轮工程为Issue #7。

## 内容与学习

R01 八单元：道路理论与历史方位、党的领导与党的建设、国家制度与治理结构、人民立场与现实国情、中国式现代化与战略安排、国家建设各领域、改革与思想工作方法、实践落实监督与反馈。历史理论实践贯穿；领导、人民、理论联系实际在各单元具体说明。

R02 每日一小时计入八小时预算：回忆5、理论15、现实材料15、独立输出20、复盘5分钟。忙碌日20分钟保底。真题小题全写；作文练提纲和论证段并阶段性完整限时写作。不安排模拟卷，不用阅读替代训练。

R03 官方渠道按用途分工，教材与学习纲要搭框架，求是读重要论述，政府网查政策，人民日报读报道和评论，学习强国补课，统计局及部委地方网站按需补数据与落实。助手负责筛选组合，尽量围绕同主题，不要求每天遍历所有平台。

R04 每课提供六项内容：核心认识、原文依据、工作机制、事实案例、题型用法、条件反例。区分需准确记忆、理解复述、按需调用。最短表述以准确完整为边界，不许承诺覆盖所有题目。

R05 理论落到实际工作，检查问题对象、职责权限、关键卡点、动作、机制条件、结果反馈。把概括、分析、对策、应用文、作文分别设计，不强套同一结构。

R06 所有核心知识政策案例可追溯。原文和提炼、部署和事实、评论和阅卷标准、真实案例和假设分别展示；来源字段及修订规则见内容标准。

R07 首答、修订、已接触参考分别保存；无提示新题以任务回应、材料要点、论证、限时完成检验。个人效果需要用户真实数据，不能由AI示范代替。

## 网站与隐私

R08 独立站点与旧站分开，默认仅所有者访问。入口包括今日学习、八单元课程、机制与写法、原文来源、建设依据。

R09 每课能回原文并进入写作任务。示范默认收起，本地草稿支持显式保存、冻结首稿和导出，刷新可恢复；存储失败须明确告知。收藏笔记不上传。

R10 手机与桌面均可阅读；键盘能操作，来源列表可搜索；导航按哈希保留直达链接。新单元未备齐须标待建设。

R11 公开GitHub仅存原创内容、源码、索引和治理文件。完整第三方材料与个人作答放忽略目录及私人站。Site源仓库和GitHub评审仓库分别记录SHA。

R12 不承诺零错误、永久最新、押题或提分。变更来源时记录差异；未配置调度不声称自动更新。课程Issue在完整课程与验证实际达成前保持开放。

## 最新验收边界：内容先行

用户明确要求先备齐八课全部MD与Word，再搬到网站。每课包含原文定位、理论讲解、工作机制、真实案例及适用边界、申论写法和独立输出。十九章建立逐章对照与实际选读记录，不声称逐节读完全文；短摘与原创讲解区分。网站提供八课全文与每课MD/Word、合订版及ZIP下载，从同一原稿生成；文档含示范，网页默认折叠。

验收八课非空、网页与原稿一致、文档可打开、Word全页渲染、手机下载阅读及各课作答隔离，保留旧课节ID。用户迁移须继续按Issue #9验证，不因正文完成关闭训练任务。
