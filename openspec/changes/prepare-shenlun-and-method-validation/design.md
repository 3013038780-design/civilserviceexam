# Design

## Context

动机见proposal。行测首答核验已完成，当前新增申论示范、方法跨卷样例和扫描范文分析。原始资料与完整答案处于忽略目录，公开仓库承载方法与必要摘要。

## Goals / Non-Goals

**Goals:** 让准备证据能追溯到原稿、题号或篇页，用户有无答案练习入口，后续Skill按任务读取已有成果。

**Non-Goals:** 本变更不替用户作答、不训练模型权重、不发布第三方全文、不以助手表现替代个人策略验证。

## Decisions

1. 首答采用JSON和冻结摘要保存，教学Markdown另存；相比直接修改成品答案，可保留首答错误与核验来源。申论只比较任务与材料，不构造官方评分。
2. 四卡各选三道2025副省级匹配题，作答在参考前保存；另构造边界反例。样例选择便于发现规则问题，代价是不能据此给泛化或因果结论。
3. 扫描文档使用本机Vision OCR；每页候选文本与篇目阅读状态分开保存。相比上传整本给外部处理，本地方式能保留路径与处理范围。OCR混栏和数字疑点通过抽查、出处定位及暂不采用处理。
4. 公共策略正文保存在根文档，Skill只加按需入口，避免多处复制规则。用户包只提供题面和空白记录；2025申论提取合订主版本前六页，参考区分开。练习副本移除原有高亮、下划线等批注，避免预先提示阅读重点；原文件保留。
5. 继续更新issue #1与PR #2，不另建重复任务。该变更验收助手准备交付，用户独立验证由原issue继续跟踪。

## Risks / Trade-offs

- OCR将侧栏混入正文 → 标注候选文本、实际抽查范围，数字和名言核验前不背。
- 机构答案存在强断言 → 回材料比较，不自动替换有据首答。
- 12题样例被误读成效果试验 → 公开选题和计时限制，分开助手与用户证据。
- 公共摘要泄露练习答案 → 完整逐题记录和练习包留本地，发布前逐个检查暂存文件。

## Migration Plan

检查首答摘要、字数与12题记录，核验30篇页码覆盖和练习包边界；验证两个Skill与OpenSpec；更新文档及issue/PR后推送。必要时通过后续提交修订摘要，冻结首答始终不改。
