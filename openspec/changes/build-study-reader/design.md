# Design

## Context

135条教学JSON和五题申论JSON已存在，原题主版本固定；公开Markdown与图示可复用。用户需要先读策略，测试不是访问教学的前提。

## Goals / Non-Goals

**Goals:** 一个学习工作台解决题目、依据和路径切换，默认推荐题117；支持本机完整阅读与私有在线界面。

**Non-Goals:** 不增加考试引擎、AI在线调用、用户评分和后台学习；不改变数量与图推取舍。

## Decisions

1. 使用无构建依赖的HTML/CSS/JS，中文大字号和双栏研习；窄屏顺排。相比先做框架应用，适合当前静态阅读和本机打开。
2. 导出脚本读冻结后教学数据，生成含题面页图的本地包和自包含HTML。按最新用户反馈，私人站点预装完整135题、五题及原图，发布前确认访问仅所有者；公开仓库仍只存代码与原创总结，本地完整版继续保留。
3. 收藏与笔记保存在浏览器，导入资料用IndexedDB缓存；持久化异常提示，记录可导出。无后端个人数据。
4. 原题页图保留真实图形和表格，以题号定位页；页图可放大，不依赖易错的PDF文字顺序重排题面。
5. Markdown仅作为资料来源，通过受限解析和转义展示；导入数据只接受预期结构与图片格式，外链限制为HTTPS。

## Risks / Trade-offs

- 原题一页含多题 → 提供题号、页码和放大查看，不声称精准重排。
- 单文件与图片包较大 → 图片控制分辨率、按当前题展示，界面不引入网络字体或追踪。
- 本机与在线浏览器存储不同 → 明示记录属当前浏览器，可导出；不承诺自动跨设备同步。
- 第三方全文被误发布 → 公开GitHub排除完整发布目录与原题；私人Sites发布目录含预装包，发布前核对owner-only访问。

6. 分类方法作为主学习入口：十一类可选，九类逐步展开动作与理由、停止点、自拟示例和真题连接，数量图推保持暂缓。单题可返回所属方法，新增方法标记待迁移检验。
