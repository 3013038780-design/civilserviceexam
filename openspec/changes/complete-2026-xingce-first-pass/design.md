# Design

## Context

动机见proposal.md。现有题面为用户确认的26页主版本，参考解析单独保存；现有两个教学Skill和首答协议可复用。OpenSpec 1.14.2已通过npm安装并为Codex初始化。

## Goals / Non-Goals

**Goals:** 用一份逐题原始记录保留首答证据，生成便于阅读的副本与公开完成摘要，后续核验可追溯。

**Non-Goals:** 本变更不计算正确率、不完成用户作答或方法迁移，不开发题库平台，不安排数量图推专项。

## Decisions

- 本地JSONL逐题追加，拒绝重复题号；每批及时保存，避免整卷结束才落盘。相较只存最终答案表，可保留保存时间与疑点。
- 首答完成后计算SHA-256、记录冻结时间并把原始文件设为只读；CSV与Markdown由原始记录生成。只读与摘要用于防止无意修改，不是可信时间戳或不可篡改系统。
- PDF文字用于定位，图形、公式和数据表通过Poppler渲染后目视读取。计算工具仅复算本人列出的式子，不读取配套解析。
- 使用本地OpenSpec根，配置只针对Codex；不启用跨仓库store和自动调度。issue管理整轮训练进度，OpenSpec任务只管理本次变更，PR承载相关文件。
- 本次同时得到用户的安装和首答执行授权，因此在建立规格后继续完成实际产物，不把仅规划工作流的停点解释为需重复取得用户授权。

## Risks / Trade-offs

- [知识措辞和图形判断可能出错] → 保留把握程度与不确定首选，核验另存，不用猜测生成教学规则。
- [模型可能历史见过题] → 记录已知101、102题接触，明确无法排除训练期间接触。
- [完整答案影响用户独立作答] → 公开仓库只保存完成记录，答案文件标注阅读前提，不在对话展开答案。
- [工具速度被误认为考生速度] → 不生成考场完成时间或人类速度估计。

## Migration Plan

配置与规格随PR提交；npm全局CLI随本机Node环境使用。后续核验新增独立目录，首答文件不改写。若停止使用OpenSpec，保留规格与证据，仅移除生成的工作流及CLI即可。
