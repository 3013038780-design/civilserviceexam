# Design

## Context

首答135题已冻结且原始文件只读。配套参考表可逐题比对，原始题面与解析均本地保留。动机及范围见proposal.md。

## Goals / Non-Goals

**Goals:** 完成答案核验与逐题可执行教学，留下可复算记录、少量可迁移方法卡和真实阶段状态。

**Non-Goals:** 不声称还原内部思考逐字记录、不计算官方分数、不推断尚未提交的用户表现，不增加数量图推专项。

## Decisions

- 对照以机构参考表为工作答案，教学依据另行判断；同答案也可能是猜中或理由不足。分歧单列，原始首答不改写。
- 本地结构化保存教学条目，再生成九个模块与合订稿，便于分批阅读。公开仓库仅存汇总及无题面全文的方法卡。
- 优先一个简短可靠入口，有实质收益再增加替代路径；同一公式改写、构造可达性或工具枚举明确属于核验，不当成新算法。
- 第54、93题高把握错题提炼为方法卡；资料分析提炼区间停止和口径锁定。方法状态为本卷例题已核验，用户新题迁移未测。
- 第87题参考省略证明，补共同棱端点分析与坐标折叠；其他图形回看原图和解析图。解释有局限时注明，不机械继承参考文字。

## Risks / Trade-offs

- [机构答案不等于官方答案] → 报参考一致率并保留推导疑点，不给官方分数。
- [多路径变成长篇负担] → 每题推荐一条，按模块阅读，其他入口可跳过。
- [事后教学被误认为首次思考记录] → 每题保留首答与修订，首页解释教学推导性质。
- [单卷高一致率掩盖能力缺口] → 报告高把握错误、低把握猜中及无用户迁移证据。
- [人工图形录入出错] → 回看原图、保留坐标脚本与24种旋转结果，教学给可目视核查的端点条件。
