# Proposal

## Why

现有站点侧重真题研习，缺少系统理解中国并转为申论表达的独立课程。用户要求将完整需求及治理落地GitHub，并另建私人网站。

## What Changes

- 独立课程目录、README、AGENTS、内容标准及每日方案。
- 八单元导航、首课示范、来源核查、本地写作与导出。
- 单独私人Site与发布记录，Issue和PR区分网站交付与后续完整课程。

## Capabilities

### New Capabilities

- `china-shenlun-course`: 可追溯课程、状态展示及独立写作体验。

### Modified Capabilities

无。

## Impact

新增sites/china-shenlun，根README和AGENTS新增入口。原网站与私人题库保持原状。本轮只完成基础及首课，完整八单元与用户迁移由Issue #8/#9跟踪。
