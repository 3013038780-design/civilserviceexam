# Spec Delta

## Purpose

为国考副省级备考者建立从官方理论到现实工作再到申论表达的独立学习入口，确保核心知识可追溯、课节状态真实，并以独立写作连接阅读与实际应用，避免将站点上线等同于课程建设或用户训练完成。

## ADDED Requirements

### Requirement: 可追溯课节

系统 SHALL 展示八单元、三条理解线及课节实际状态；每个示范课节 SHALL 提供核心认识、工作机制、案例边界、来源定位、核验日期和写作任务。

#### Scenario: 打开首课

- **WHEN** 用户打开首课
- **THEN** 可阅读明确标识的原创提炼并进入原文，案例事实与解释分开

#### Scenario: 打开未建单元

- **WHEN** 用户选择其余单元
- **THEN** 展示待建设状态与学习目标，不宣称课节完整

### Requirement: 独立输出

系统 SHALL 默认隐藏示范，允许保存草稿、另存冻结首稿及导出；数据 MUST 仅保留当前浏览器，存储失败 SHALL 明确提示。

#### Scenario: 保存与刷新

- **WHEN** 用户保存草稿并刷新
- **THEN** 可恢复文本，冻结首稿不会因后续保存被覆盖

### Requirement: 独立私人发布与治理

网站 MUST 独立于原站且保持仅所有者访问；项目 SHALL 提供需求、README、AGENTS、Issue和PR入口，完整课程及用户迁移保持单独跟踪。

#### Scenario: 项目交付

- **WHEN** 首版上线
- **THEN** 提供实际发布URL与核验记录，完整课程和用户迁移仍标未完成
