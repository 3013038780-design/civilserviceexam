# Design

## Context

现有九类流程主要来自2026一卷，2025仅四卡12题已有旧验证。桌面现有2000—2026年材料，50个主卷阅读单元已经可按年份和原卷别组织；其中2024一份未标卷别合订保留独立阅读入口，不为确认身份阻塞阅读。

## Goals / Non-Goals

**Goals:** 把题面阅读转成可核查的任务分类和可执行技能，按2010年（含）及以后主版本继续未完成任务；50单元作为历史目录，早期已完成成果保留而未分析部分不再推进；同类跨年；阅读、逐题策略检验、可视化教学与个人迁移分开验收。

**Non-Goals:** 不读取或训练模型权重，不承诺复制隐藏思维，不要求用户先交卷才允许助手继续研究，不新增数量或图推专项训练。

## Decisions

1. 分开保存程序抽取清单与人工阅读/视觉检查记录。自动生成全文不提升阅读状态，避免把扫描进度说成理解进度。
2. 保留十一类学习入口，操作层用多标签与任务分支。题号只作为来源定位，不能按固定题号区间跨年份分类。
3. 全量文字阅读后检查图形、表格、缺失公式。数量图推阅读仅用于完整题型识别，不转成专项作业。
4. 原创方法页记录动作和理由；完整题面与答案只放本地忽略目录或所有者私人站点。分类推导与参考比较分别记录，旧首答不可覆盖。
5. 近期变化采用逐年可见证据与官方大纲对照；某题在2025出现不能推出其2025首次出现。历史阅读尚未完成时不宣称新题型起源。
6. 每条候选规则用正例和失效反例检查。助手跨题检查与用户个人效果分开，不设虚构掌握率。

## Risks / Trade-offs

- 图文抽取缺失 → 保留页码并逐图阅读，低分辨率拼图只用于定位，关键图另渲染。
- 大量同题跨卷重复 → 使用已有主版本，记录重复可能性但不重开版本审计。
- 长解析仍难模仿 → 规则拆成识别、动作、理由、停止、边界、例题，默认只推荐一条。
- 对历史时政作现行推断 → 标题目年份，涉及当前事实另查权威来源。
- 全量工程跨多轮 → 每轮留下具体页码、发现和下一读取位置，任务未完成保持开放。


## 执行顺序（2026-10-18用户明确授权）

1. 将长期目标置于AGENTS.md开头，统一Skill、计划、续接；现有历史阅读勾选不等于策略检验完成。
2. 从主目录、题型队列、冻结首答与核验记录建立逐题策略清单。状态为尚未阅读、已读待策略检验、已有策略检验、需要回查、存在争议；程序只关联证据，不凭字母或关键词认定有效。自动候选分类保持待核，无法关联列缺口。50单元须全部有汇总，解析定位失败不冒充完整题数。
3. 复用定义三批80来源位置逐题审阅分支、执行、知识与争议；先完成普通条件匹配、多定义包含方向两样板，每个提供可检查的决策节点、短步骤、成功与失败/边界示范和选择依据。另三分支保留既有结果，随后完善。
4. 继续定义全量：先已读待检验，再未读；组内年份降序，同年主目录顺序。每批20题，复杂/共享/大量分歧10题，题组不拆。全部题处理不等于全部题无争议。
5. 每批明确问题与题单→读题及图像→复用或冻结首答→对应方法及版本→核验归因→修正规则→回查依赖旧题→保存教学与检查点。旧首答不覆盖；相同字母也核理由。
6. 定义全量后按资料（口径可求、基期增长增量、比重平均、综合）、中心排序（主旨、填句、排序）、阅读（细节推断、机制、篇章）、选词（单空、多空、辨析）、逻辑（论证、条件、真假、共享）、类比（基本、二级方向、三词）、政治、常识顺序；每类先旧证据再未检验题。真实新任务可细分，不强塞分类。
7. 每批立即保存；完整教学单元、重要规则修正、线上学习错误或用户要求时发布。能力地图→首选流程→示范默认可见，证据折叠。保留135题、个人笔记与私人访问权限。无界面机制改动只做相关内容及引用检查，输入不变不重复构建。
8. 每个可学分支准备3—5题未讲试用入口，是否用户未做过待确认，答案分离。个人迁移未知不阻塞助手研究；困难先改教学再加解析。申论独立执行任务→材料→要点→概念论证→真题检验。
9. 每轮以能力目标、问题、具体题单、方法版本、修改与回查、下一批题单及发布实态续接；四类进度分别报告，不维护重复总表。

## 数据与回查约定

逐题策略清单在忽略目录生成，只把已有证据作可追溯关联；方法候选与人工审阅分开。首答、参考及判断保持各自记录，不从答案相等推断成功。方法版本固定到教学规则内容；回查登记受影响方法、旧题、原因、完成与遗留。旧记录未写完整步骤的标依据不全，不能伪装当时使用现版本。

自动化只减索引和重复维护，不代替阅读和判断。教学字段可选扩展能力地图与流程节点，旧卡无新字段仍可显示。公开文件不含完整题面/参考和私人作答。


## 年份范围修订（2026-10-18）

用户明确要求未分析题只做到2010年，含2010，不再追溯2009年及以前。现有50单元目录中35个属于当前年份范围、15个属于历史保留；不删除原件、首答和既有策略记录，不把排除部分勾为完成。类别顺序、逐题闭环和私人发布规则保持。历史定义/资料50单元验收不撤销；后续全量指当前年份范围。新增题、发现来源与显式续接均读取research-scope.json；仅已有成果因规则修订需要纠错时允许最小依赖回查，不借此扩展旧题研究。历史总数与当前范围覆盖分别报告。申论未来未分析真题沿用同一年份下限。


## 当前阶段修订：言语理解与判断推理优先（2026-10-19）

用户明确要求先完成两块：中心句与排序（含插入等真实任务）→阅读理解→选词填空→逻辑判断→类比推理；定义复用既有处理，必要时依赖回查。图推按此前决定继续暂缓。资料、政治、常识和申论不再安排本阶段新增研究，既有记录保留；当前阶段完成前不自动恢复。年份仍2010年（含）起，历史范围及成果不删、不重算。

文理结合按证据与操作成本验收：言语用条件、集合、因果、量词和反例检查直觉；推理保留语境、概念及表达目的后形式化，并回译核对。不是每题强制写两套解法；混合方法不能改善正确性、稳定性或步骤成本时撤回。当前题目覆盖、策略检验、可视化和个人迁移分别报告，缩小当前目标不作全量完成。

## 最小可分享闭环（2026-10-20用户授权）

本轮仅改善下文预测这一分支的教学入口：一题白话示范，随后3道明确标注的原创自拟试用。用户选择、依据和自报用时先保存，提示接触单列；打开核验不改首答，最后记录下一动作并可导出。只有当前步骤默认展示，其他方法与历史研究入口折叠保留。用独立单文件HTML提供可离线、可分享入口，不依赖私人完整题库，不改网站访问权限。原全量研究与逐分支验证任务保持未完成，来源覆盖和个人迁移不因界面交付增加。
