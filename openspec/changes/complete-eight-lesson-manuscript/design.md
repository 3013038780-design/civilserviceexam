# Design

## Context

用户要求内容先于页面。参见proposal.md。

## Goals / Non-Goals

先完成八课MD和Word再改网站，不将目录视为课文。全书十九章用主题与原文定位覆盖，实际精读范围单列，不声称逐节精读完毕。

## Decisions

manuscripts是正文唯一来源；生成脚本产出Word、合订稿和ZIP。网站同步同一文本，默认折叠原创表达示范。沿用原站身份与私人受众，按课ID隔离草稿；旧首课ID保留。Word使用工作区runtime与本地字体完成渲染，检查中文、分页与链接。

## Risks / Trade-offs

原文扫描图可能无法抽文→交叉查本地文本及原页图注。中文字体缺失→任务内字体配置并重渲染。理论简化失真→保留必要概念、适用条件及出处。网页不等于掌握→状态标待用户迁移。
