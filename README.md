# AI辅助国考备考

围绕2027年国考副省级，探索如何把AI提供的可靠解法、名师方法和真实作答反馈转化为考生能够独立执行的策略。

当前行测目标是稳定65分。主要学习最简可靠解法，不主动投入数量关系与图形推理专项；申论从题干和材料训练破题、要点加工与论证，同时建立可迁移的表达和案例库。以无辅助、限时、新题表现验证效果。

> 已完成2026行测135题首答与教学、四卡跨卷12题样例检验、2026申论五题首答核验与材料映射，以及30篇混合范文汇编的结构初析。用户独立迁移仍未测，不换算官方分数；二十年真题和500篇范文未全量分析。先看[回来后从这里开始](回来后从这里开始.md)。

## 从这里开始

1. 阅读[协作约定](AGENTS.md)，了解必须执行的要求及待验证假设。
2. 阅读[目标表与2026对照协议](备考目标与2026对照协议.md)，了解目标正确数、计分限制与双方独立作答方式。
3. 参考[考前44天节奏](国考副省级44天备考节奏.md)，按实际表现调整任务。
4. 使用对应教学Skill，提交题目或可读资料；先保存作答，再核验和整理方法。

## 教学Skills

Skills位于项目的`.agents/skills/`目录，包含教学规则和参考协议，依赖宿主AI执行，并非已经训练好的新模型。

| Skill | 用途 | 参考协议 |
| --- | --- | --- |
| [xingce-strategy](.agents/skills/xingce-strategy/SKILL.md) | 按题型学习最简可靠解法，给出识别信号、条件与停止规则；对照用户和AI作答 | [十一类读题与六维观察](.agents/skills/xingce-strategy/references/modules.md)、[独立对照与方法卡](.agents/skills/xingce-strategy/references/comparison.md) |
| [shenlun-strategy](.agents/skills/shenlun-strategy/SKILL.md) | 从副省级题干和材料建立破题、要点和论证方法 | [语料登记与迁移](.agents/skills/shenlun-strategy/references/corpus.md) |

在支持项目Skills的客户端打开此仓库后，可尝试：

```text
使用 $xingce-strategy 分析这道题，先给最简可靠解法，有价值时再比较其他路径。
使用 $shenlun-strategy 分析题干与材料，先说明立意依据，再组织提纲。
```

若客户端未自动发现Skill，可直接要求读取对应`SKILL.md`及其相关参考文件。不要把格式校验通过理解为教学效果已验证。
